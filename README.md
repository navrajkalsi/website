# Portfolio Website

[![Website Demo](./demo.png)](https://navrajkalsi.com)

Personal portfolio website.

Served by [Server-C](https://github.com/navrajkalsi/server-c).
Proxied by [Proxy-C](https://github.com/navrajkalsi/proxy-c).

Visit here: [navrajkalsi.com](https://navrajkalsi.com).

<br>

The site is completely dynamic and makes full use of the **GitHub API** & **asynchronous** programming.
All the information regarding projects is fetched during runtime from GitHub.
